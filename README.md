# Guess the Number Game

コンピュータが隠した数字を当てる、コマンドライン用の数当てゲームです。

## 動作環境

- Ruby 3.0 以上（標準ライブラリのみ使用。追加の gem は不要）

## 遊び方

```bash
ruby guess.rb
```

1. 難易度を番号で選びます
2. コンピュータが選んだ数字を予想して入力します
3. 「大きい / 小さい」のヒントを頼りに、回数制限内に正解を目指します

## 難易度

| 番号 | 難易度 | 数字の範囲 | 回数制限 |
| ---- | ------ | ---------- | -------- |
| 1    | 易しい | 1〜10      | 5 回     |
| 2    | 普通   | 1〜100     | 10 回    |
| 3    | 難しい | 1〜1000    | 15 回    |

## 機能

- **ヒント表示**：正解との差に応じて「かなり大きい」「少し小さい」などのヒントを表示します（範囲の 5 分の 1 を境に切り替え）
- **回数制限**：制限回数内に当てられなければゲームオーバーになり、正解が表示されます
- **入力チェック**：数字以外・空の入力・範囲外の数字は回数に数えず、再入力を求めます
- **履歴の記録**：結果を `history.txt` に 1 行ずつ追記します
- **中断**：`Ctrl + C` または `Ctrl + D` でいつでも終了でき、正解が表示されます

## 実行例

```
難易度を選んでください。
  1: 易しい（1〜10、5 回まで）
  2: 普通（1〜100、10 回まで）
  3: 難しい（1〜1000、15 回まで）
番号を入力してください: 2
1 から 100 までの数字を当ててください。チャンスは 10 回です。
入力してください: 80
かなり大きいです。もっと小さい数字です
残り 9 回です
入力してください: 50
少し大きいです。もっと小さい数字です
残り 8 回です
入力してください: 42
正解！ 3 回で当てました
```

## 履歴ファイル

`history.txt` はゲームと同じディレクトリに自動で作成され、遊ぶたびに次の形式で追記されます。

```
2026-10-12 14:30:15 難易度:普通 結果:正解 回数:3 正解:42
```

結果は「正解」「ゲームオーバー」「中断」のいずれかです。

## カスタマイズ

難易度ごとの範囲や回数制限は、`guess.rb` 冒頭の `DIFFICULTIES` を編集すると変更できます。
